# Research publication workspace

Keep reusable templates and case-specific data separate. Only approved public case material belongs in `content/articles/`. Do not commit original investigation PDFs, private metadata, review notes, account data, credentials or transfer manifests.

Preserve the unmodified v2.8.2 cover generator, original logo and licensed fonts. Cover text may change; fixed layout and font geometry may not. Shorten overflowing text instead of shrinking it.

Preserve source units, exact amounts, snapshot dates and stated uncertainty. No live-balance or independent verification claims are made by this site. Maintain readable color-independent labels and accessible alternatives for interactive figures.

Before finishing code changes, run `npm run check` and `npm run test:e2e`. Inspect relevant desktop/mobile screenshots. Do not deploy publicly or change repository visibility without explicit authorization. New pull requests must be drafts unless the user explicitly requests otherwise.
